# HUI-2626 finish-r1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Leads 正式路由成品化到票面 9 代表页要求：token 激活、统一列表+筛选+抽屉详情、renderer 原语替换裸控件、红线清零，真实数据链路全程不动。

**Spec:** DECISIONS.md（本 worktree 根，含 9 代表页差距表 + D1-D3 拍板）+ HUI-2626 票面（Linear，A/B/C 组实施要求）。
