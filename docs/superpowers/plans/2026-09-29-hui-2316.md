# HUI-2316 租户映射稳定化 Implementation Plan

**Goal:** 显式、稳定的来源租户映射。同 ID 本地租户后出现不改变已接收事件的归属；重放、撤销和跟进摘要读同一目标。

**Architecture:** 纯函数 `tenantmap` 解析配置和已落库决定。inbox / revocation 记下源 tenant、目标、版本和依据。接收在重放路径上不重新解析。

**Spec:** `docs/superpowers/specs/2026-09-29-hui-2316-design.md`

**Baseline:** `d085f44051ff560a27f4a4840af2dffeeb9ccdc1`

## Constraints

- 不新增身份服务或功能总开关。
- 不迁移生产客户，不发送营销，不改 touch-engine。
- 配置重复或非法时整份绑定失效，不用「先写的那条」。
- 数据库读错误不是 not found。
- 已有 event 重放不随当前配置漂移。
