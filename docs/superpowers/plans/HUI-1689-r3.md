# HUI-1689 R3 沙箱调度 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在 `sopreach` 内用夹具调度提醒、草稿和有权测试角色确认，并且默认不自动发送。

**Architecture:** `Decide` 继续做确认门，不在本轮修改。新的 `Sandbox` 只向调用方给的夹具地址 POST。HTTP 200 记为提交受理，送达保持 `unknown`。响应正文丢弃。自动发送默认关闭；接管、退订、撤销、静默时窗和频控会作废已排队的自动动作。

**Tech Stack:** Go 标准库。测试命令 `GOWORK=off go test ./internal/sopreach/ -count=1`。

**Spec:** `docs/superpowers/specs/HUI-1689-r3.md`

## Global Constraints

- 不改 `decide.go` 的确认前才允许进入发送门。已有测试保持原样。
- 不改 matrixhandoff、crafthandoff、reception、lightcopy、crmtenant、store、web、httpapi、migrations、`go.mod`、`go.sum`。
- 不引入 shadcn。不发送真实短信、邮件或企微。不占用 18101，不绑定 18120、18084、8080、8081、5173。
- 浏览器走查本轮不跑。
- 夹具不是正式渠道。不写已送达、已回复或自动触达已成功。
- `service_provider=NOT_VERIFIED`，`billing=NOT_VERIFIED`，`production=NOT_AUTHORIZED`，`human_adoption=UNKNOWN`。
- `charge_writes=0`，`billing_passed=false`，`provider_calls=0`。夹具 POST 不计成供应商调用或扣费。
- 每个结果带 `正式渠道未验证`。
